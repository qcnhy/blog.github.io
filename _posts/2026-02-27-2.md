## 前言

双持用户，想用苹果手机控制安卓手机，用[magiskWiFiADB](https://github.com/mrh929/magisk-wifiadb)和zerotier解决网络问题之后，在苹果商店找到scrcpy-remote，但是卖3美元或者22港币，网上别人买了6人民币，不甘心，找ipa包的时候发现它是个开源的。

## 特色

- 支持通过WiFi与ADB的SCRCPY传输;
- 通过硬件解码，耗电和CPU消耗更少;
- 针对移动设备不稳定网络优化手势体验;
- 支持从 URL 方案启动 SCRCPY;
- 支持配对代码配对安卓设备;
- 配备安卓导航按钮：返回、主页、切换应用;
- 支持切换 iOS 键盘并将按键发送到远程设备;
- iPhone与远程安卓设备同步剪贴板内容;
- 支持adbkey管理：生成、修改、导入、导出;
- 支持音频转发到 iPhone（适用于 Android 11+ 设备）;

## 用法

#### ADB模式：

安装应用后，默认模式是VNC。您可以通过以下选项之一切换到 ADB WiFi 模式：

1. 点击 [scrcpy2://adb](scrcpy2://adb) 访问此网址方案
2. 在主机文本框中输入文本，然后点击连接adb
3. 在端口文本框中输入文本，然后点击连接5555
4. 然后请确保安卓设备已启用adb tcpip模式：

   adb tcpip 5555

在你的安卓设备上授权后，scrcpy 将继续连接。

或者配对代码：

这只适用于Android 10+设备：

1. 点击`...` （Scrcpy Remote 主窗口左上角的菜单图标）;
2. 点击`与配对代码配对`;
3. 然后在安卓设备上，选择：

   Settings -> System -> Developer Options -> Enable Wireless Debugging -> Pair device with pairing code

然后在安卓设备上按照提示开始配对。

#### VNC模式：

您可以通过以下选项之一切换回VNC模式：

1. 点击 [scrcpy2://vnc](scrcpy2://vnc) 访问 URL Scheme
2. 在主机文本框中输入文本，然后点击连接vnc
3. 在端口文本框中输入文本，然后点击连接5900

注意：VNC模式只能连接通过websockify代理的VNC端口，且基于noVNC（一个网页虚拟客户端），所以性能和体验可能不理想。

#### 网址方案：

更改选项后，你可以点击`复制 URL Scheme`获取 URL Scheme 字符串，并且可以在 Shorcuts.app 中创建快捷方式快速连接到 scrcpy。

    scrcpy2://example.com:5555?bit-rate=4M&max-size=1080
